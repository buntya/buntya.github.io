# Apps Support Site

個人開発アプリのサポートサイトです。  
このリポジトリは、App Store公開用のサポートページおよびプライバシーポリシーを管理するための公開サイト専用リポジトリです。

## 公開ページ

- トップページ: https://buntya.github.io/
- 特別費アプリ: https://buntya.github.io/apps/special-expense/
- サポート: https://buntya.github.io/apps/special-expense/support/
- プライバシーポリシー: https://buntya.github.io/apps/special-expense/privacy-policy/

## 運用ルール

このリポジトリには、以下を含めないでください。

- アプリ本体のソースコード
- 設計資料
- 内部メモ
- APIキー
- 証明書
- 個人情報
- 非公開の開発メモ

## 今後の拡張

将来的に複数アプリを追加する場合は、以下のように `apps/` 配下にアプリごとのページを追加します。

```text
apps/
├── special-expense/
└── next-app/
```
